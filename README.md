# CornNet Trained Models

This repository provides trained CornNet model weights for two
corn-ear classification tasks evaluated in the associated study:

- Variety purity classification
- Husk status classification

## Files

The ZIP archive in this repository contains the trained model files.
Download and extract the archive before use.

## Model information

- Architecture: CornNet
- Input image size: 224 × 224 pixels
- Number of output classes: 2
- Parameters: approximately 0.102 million
- Computational cost: approximately 0.070 GMACs per image

The two tasks use separately trained models. In the experiments
reported in the study, the models were deployed independently
according to the sorting task.
